# Sales Analysis Project

## 📌 Project Overview

This project focuses on analyzing sales data using **MySQL** and **Tableau** to understand sales performance, product performance, category-wise sales, order quantity, and sales trends over time.

The project includes SQL-based data analysis and an interactive Tableau dashboard.

## 🛠️ Technologies Used

* **MySQL** – Data storage and SQL analysis
* **Tableau** – Data visualization and dashboard creation
* **GitHub** – Project version control and sharing

## 📊 Dashboard Features

The Tableau dashboard provides:

* Total Revenue
* Total Quantity
* Total Orders
* Sales by Category
* Sales by Product
* Sales Trend over Time
* Category filter
* Year filter
* Interactive dashboard

## 🔍 SQL Analysis

SQL queries were used to analyze the sales data and obtain useful business information such as:

* Total sales/revenue
* Total quantity sold
* Number of orders
* Category-wise sales
* Product-wise sales
* Sales trends

The project provides a visual overview of sales performance and helps identify:

* High-performing products
* Category-wise sales performance
* Sales trends
* Overall revenue and order performance

## 🚀 How to Use

### SQL

Open `sales_analysis.sql` using **MySQL Workbench** and execute the queries using the required sales database.

### Tableau

Download `Sales_Performance_Dashboard.twbx` and open it using **Tableau Desktop** to view and interact with the dashboard.
